# RescueCast 智能无障碍应急沟通平台

[在线体验](https://rescuecast.onrender.com/) · [英文项目主页](README.md)

RescueCast 将复杂的应急通知整理为标准通告、易读版本、英文摘要和行动清单，并提供真实地图定位、重点受众设置、现场图片、人工核验、语音朗读和一次性反馈。

## 主要功能

- 十类常见事件与自定义事件。
- 事件时间、风险等级、影响区域、原始通知和重点受众配置。
- 输入具体地点后通过 ArcGIS/Nominatim 定位，使用 OpenStreetMap 展示风险区域。
- 标准通告、易读版本、英文摘要和行动清单。
- 最多四张现场图片，每张不超过 8 MB。
- 发布前必须完成人工核验清单。
- 匿名浏览器身份只能提交一次“有帮助/需改进”评价。
- 大字号、增强对比度、减少动画和浏览器语音朗读。

## 本地运行

```bat
corepack prepare pnpm@9.15.9 --activate
pnpm install --frozen-lockfile
pnpm dev
```

打开 <http://localhost:3000>。本地数据库和图片默认写入 `.rescuecast-data`，该目录不会提交到 GitHub。

## 重要边界

通告和行动指引使用规则模板生成，不是官方预警、灾害预测或调度系统。地图风险半径仅用于界面演示。Render 免费实例的 `/tmp` 存储会在重启或重新部署后丢失；正式产品需要账号权限、持久数据库、对象存储、审核和官方数据源。
